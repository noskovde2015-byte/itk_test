## Развёртка
Для развёртки приложения потребуется Docker.

После его установки (или включения) необходимо выполнить следующие шаги:

С помощью терминала, находясь в корне проекта, выполнить команду

```shell
docker build . -t app 
```

После успешной сборки выполнить команду:
```shell
docker run -p 5000:8000 -it app   
```


После этого приложение готово к работе.
